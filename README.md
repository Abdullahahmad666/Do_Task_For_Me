# Do Task For Me — Android Service-Ordering App

An Android app where students and clients can browse services, place orders for assignments and projects, and track them, while an admin manages incoming orders. Built with **Java and Firebase**.

## Features
- Splash screen, sign-up and login with Firebase Authentication
- Home, Services, Projects, Assignments, About Us and Contact Us screens (fragments)
- Place an order and see order details
- Admin panel to manage and update orders
- Contact Us form

## Tech
Java · XML · Android Fragments · RecyclerView adapters · Firebase · Android Studio

## Run
1. Open in Android Studio and let Gradle sync
2. Add your own `google-services.json` from the Firebase console to `app/`
3. Run on an emulator or device
